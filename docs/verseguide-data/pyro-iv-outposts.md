### Where the coordinates come from

Not in the SSR payload. They live on the Three.js map's data objects, reachable from the
Vue tree via `document.querySelector('canvas').parentElement.__vue__` — walk it and match
on the POI's `name` field to pick up its `lat` / `lon` / `altR`. The Firestore listen
channel carries the same data but the REST API needs auth.

## Citizens for Prosperity — verified lore

From the Star Citizen Wiki (https://starcitizen.tools/Citizens_for_Prosperity):

- Originally "Citizens for Pyro"; now Citizens for Prosperity.
- Founded **2950** by **Madge "Dash" Harford**. Lead dispatcher: **Lima Endicott**.
- Stated focus: **Security** and **Community Service**; intent to "tame the infamous
  outlaw system once and for all."
- Work evolved from hunting criminals into a **resettlement plan**.
- Headquarters in **Lorville** and **Hurston** (Stanton).
- Posts: Monox (Jackson's Swap, Sunset Mesa, Yang's Place), Bloom (Bueno Ravine, Frigid
  Knot, Narena's Rest, Shepherd's Rest), Ignis (Kabir's Post), Terminus (Bullock's Reach,
  Canard View).

**They are a frontier law-enforcement/militia organisation, NOT an insurgency against the
UEE.** An early draft of the Sacren's Plot page got this wrong — the CFP does not "fight
the UEE's control of Pyro". They are the people trying to end the outlaw trade, which is
what makes their posts safe-ish places to do business. Correct framing.

Their outpost naming convention is a person's name plus a place ("Sacren's Plot",
"Chawla's Beach", "Jackson's Swap", "Kabir's Post"), which is where the page's naming
note comes from.

## Integration notes for whoever picks this up

- Adding a PHDS location needs **three** edits (see CLAUDE.md): the `.mdx` file, the `entries`
  array in `src/pages/phds/index.astro`, and the same array in `src/pages/pyro/phds/index.mdx`.
- `type` must be one of `POIBadge`'s 10 canonical values. VerseGuide's own types (Outpost,
  Salvage Yard, Depot, Derelict Outpost) are a **different** vocabulary — map them, don't
  invent new badge values.
- Existing Pyro IV guide: `src/pages/pyro/pyro-4/index.mdx` (79 lines) already has 3
  `AttractionEntry` sights: The Mud Flats, The Overlook, The Salvage Yards. Note the
  Salvage Yards entry describes a *settlement*; VerseGuide's roster has Chawla's Beach as the
  "Salvage Yard" type on Pyro IV. Reconcile before adding anything that contradicts it.
- `src/data/verseguide/pyro.json` is the provenance record for this system — extend it with
  the Pyro IV outposts. Its `$schema` points at `src/schemas/verseguide-system.json`, which
  **does not exist**; either write that schema or drop the `$schema` key.
- Attribution components exist but **no page references them yet**:
  `ImageAttribution` (full credit), `TextAttribution` (inline link), `VerseGuideCredit` (footer).
