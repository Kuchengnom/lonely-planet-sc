# Lonely Planet: Star Citizen

> Unofficial travel guides to the 'Verse.
>
[🌐 Live Site](https://kuchengnom.github.io/lonely-planet-sc/)

Curated attractions, hidden gems, and essential travel tips for the systems you fly through. Built in the editorial spirit of classic travel writing — for explorers, by explorers.

---

## Quick Start

```bash
# Install dependencies
npm install

# Start the development server (with hot reload)
# → Opens at http://localhost:4321
npm run dev

# Build for production
npm run build

# Preview the production build
# NOTE: Must run `npm run build` first!
npm run preview
```

---

## Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Starts the Astro dev server at `http://localhost:4321` (hot reload enabled). |
| `npm run build` | Builds a static version of the site into the `dist/` folder. |
| `npm run preview` | Serves the built `dist/` folder locally for testing. Requires `build` first. |
| `npm run astro` | Direct access to the Astro CLI. |
| `npm run build:od` | Builds the site and exports self-contained HTML pages to `od-export/` for Open Design. |
| `npm run sync:tokens -- <file>` | Reads an Open Design-exported HTML file and syncs changed CSS variables back to `src/styles/design-system.css`. |
| `npm run test:scripts` | Runs unit tests for the `scripts/` build utilities. |

## Open Design Workflow

The site can be visually edited in [Open Design](https://opendesign.dev/) with real Star Citizen content visible. Design token changes made in Open Design (colors, typography, spacing) can be synced back to the codebase automatically.

### Export to Open Design

```bash
npm run build:od
```

This builds the site and post-processes each page into a self-contained HTML file in `od-export/`. Import any file from that folder into Open Design — you'll see the real guide content while editing the visual design.

### Sync token changes back

After making visual edits in Open Design and exporting the result:

```bash
npm run sync:tokens -- path/to/exported-page.html
```

The script reads the CSS variables from the exported file, diffs them against `src/styles/design-system.css`, and patches only the values that changed. It prints a clear before/after diff so you can review what changed before committing.

One exported page is enough — all pages share the same tokens.

### Round-trip workflow

```
1. npm run build:od
2. Import a page from od-export/ into Open Design
3. Edit visually (colors, spacing, typography)
4. Export the edited HTML from Open Design
5. npm run sync:tokens -- path/to/exported.html
6. Review the printed diff
7. git commit src/styles/design-system.css
8. npm run build  (deploys updated tokens)
```

**Note:** `od-export/` is gitignored — it's a local working directory only. Structural component changes (layout, markup) are made in the Astro source files directly.

## Why no `npm start`?

This project uses Astro's modern scripts (`dev`, `build`, `preview`). There is no `start` script defined — use **`npm run dev`** for development or **`npm run preview`** to check a production build.
