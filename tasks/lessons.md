# Lessons

- When a destination is covered by attractions, tours, and a practical section, each occurrence must add a distinct purpose. Do not repeat the same venue narrative in the dining section; link its practical guidance to the existing destination coverage instead.
- A visually rich homepage still fails when its first actions point at unrelated journeys. Make the first viewport answer one decision completely — here, choosing a system — before introducing a system-specific itinerary.
- Persistent progress markers must be explicit user actions. Never infer “I have visited” from hover or passive pointer movement; provide a reversible control with a visible state and local persistence.
